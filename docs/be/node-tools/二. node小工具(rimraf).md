# 二. node小工具(rimraf)

> 原文出处：https://blog.csdn.net/qq_35812380/article/details/126330630

> 用于快速删除`node_modules`包

一. 安装 `rimraf`

```
npm install rimraf -g
```

二. 执行如下命令删除`包`

> 在项目根目录执行该命令, 可以快速

```
rimraf node_modules // 也可以删除其它文件夹或文件
```

三. 可在`package.json` 中配置`clean`命令快速删除

```
  "scripts": {
  ...
+ "clean": "rimraf node_modules"
  },
```
