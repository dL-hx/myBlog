# 函数式编程范式

## 概述
函数式编程（Functional Programming，FP）是一种编程范式，它将计算视为数学函数的求值，并避免使用程序状态以及易变对象。

## 核心概念

### 纯函数（Pure Functions）
- 相同的输入总是产生相同的输出
- 没有副作用（不修改外部状态）

### 不可变性（Immutability）
- 数据一旦创建就不能被修改
- 任何"修改"都会创建新的数据副本

### 高阶函数（Higher-Order Functions）
- 函数可以作为参数传递
- 函数可以作为返回值

### 函数组合（Function Composition）
- 将多个简单函数组合成复杂函数

## JavaScript中的函数式编程

### 数组方法
```javascript
// map, filter, reduce
const numbers = [1, 2, 3, 4, 5];
const doubled = numbers.map(x => x * 2);
const even = numbers.filter(x => x % 2 === 0);
const sum = numbers.reduce((acc, x) => acc + x, 0);
```

### 柯里化（Currying）
```javascript
const add = a => b => a + b;
const add5 = add(5);
console.log(add5(3)); // 8
```

### 函数组合
```javascript
const compose = (f, g) => x => f(g(x));
const toUpperCase = x => x.toUpperCase();
const exclaim = x => x + '!';
const shout = compose(exclaim, toUpperCase);
console.log(shout('hello')); // "HELLO!"
```

## 优势与劣势

### 优势
1. **可预测性**：纯函数使代码更易于理解和测试
2. **可维护性**：不可变性减少了意外的副作用
3. **并发安全**：没有共享状态，适合并行处理
4. **模块化**：函数组合促进代码复用

### 劣势
1. **学习曲线**：需要思维模式的转变
2. **性能开销**：不可变性可能带来内存和性能开销
3. **生态系统**：JavaScript原生支持有限

## 实际应用场景

### 数据处理
- 数据转换和清洗
- 报表生成
- 数据分析

### UI开发
- React组件（纯函数组件）
- 状态管理（Redux的reducer是纯函数）

### 异步编程
- Promise链式调用
- async/await与函数式结合

## 最佳实践

1. **优先使用纯函数**
2. **避免副作用**
3. **使用不可变数据**
4. **利用函数组合**
5. **适当使用柯里化**
