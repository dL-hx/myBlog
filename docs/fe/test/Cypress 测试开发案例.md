## Cypress 测试开发案例

### 准备练习案例

```
git clone https://github.com/lipengzhou/vue-realworld-example-app.git

cd vue-realworld-example-app

npm i

npm run serve
```

### 配置 Cypress 测试环境

```
vue add e2e-cypress
```

```
npm run test:e2e
```
